# Fuel Guardian App

AI IMMERSION PROJECT  -  Problem Statement                                                                        Small fuel leaks are easy to miss — until they become costly or unsafe.                                       Fuel leakage causes wastage, financial loss, pollution and safety risk. This project uses sensors and AI to monitor fuel data, identify abnormal changes and warn the driver early. create a app
